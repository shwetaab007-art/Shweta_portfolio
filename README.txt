PERSONAL PORTFOLIO WEBSITE - SHWETA SARA ABRAHAM

PROJECT FILES
- index.html: Home page with introduction and profile photo
- about.html: Self introduction, education and interests
- projects.html: Skills and projects
- contact.html: Contact form and social links
- style.css: Shared website styling
- images/: put profile.jpg here

HOW TO RUN
1. Extract the MyPortfolio folder.
2. Open the folder in Visual Studio Code (File > Open Folder).
3. Open index.html in a web browser (or use the Live Server extension).

HOW TO PUT IT ON GITHUB
1. Create a new repository and upload all files and the images folder.
2. In the repository, open Settings > Pages and choose the main branch.

BEFORE SUBMISSION
- Add your photo as images/profile.jpg.
- Add your school names and years in about.html.
- Replace the sample skills and projects in projects.html.
- Replace yourname@example.com and the social links in contact.html.

NOTE
The contact form is only a front-end demonstration. The mailto action opens
the visitor's email application and does not save messages.
